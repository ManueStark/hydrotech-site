# hydrotech-site

Bienvenue sur le dépôt du site web Hydrotech, votre plateforme d'innovation en solutions hydrauliques et technologiques en Afrique.

## 🌍 À propos

Hydrotech est une entreprise dédiée à la fourniture de solutions technologiques avancées et durables pour les défis hydrauliques et énergétiques en Afrique. Notre site web présente nos services, réalisations et informations de contact.

## 🚀 Installation

### Prérequis

- Node.js (v14 ou supérieur)
- npm ou yarn
- Git

### Étapes d'installation

```bash
# Cloner le dépôt
git clone https://github.com/hydrotechafricaci-lab/hydrotech-website.git

# Naviguer dans le répertoire
cd hydrotech-website

# Installer les dépendances
npm install
# ou
yarn install
```

## ⚙️ Configuration

### Variables d'environnement

Créez un fichier `.env.local` à la racine du projet :

```env
REACT_APP_API_URL=https://api.hydrotech.com
REACT_APP_ENV=development
```

### Lancer le serveur de développement

```bash
npm run dev
# ou
yarn dev
```

Le site sera accessible à `http://localhost:3000`

## 🤝 Contribution

Les contributions sont les bienvenues ! Pour contribuer :

1. Créez une branche pour votre fonctionnalité (`git checkout -b feature/AmazingFeature`)
2. Commitez vos changements (`git commit -m 'Add some AmazingFeature'`)
3. Poussez vers la branche (`git push origin feature/AmazingFeature`)

## 📝 Convention de commit

Veuillez suivre les conventions de commit standardisées :

- `feat:` Nouvelle fonctionnalité
- `fix:` Correction de bug
- `docs:` Documentation
- `style:` Changements de formatage
- `refactor:` Refactorisation du code
- `test:` Tests
